# Plan — Port Codex Titanium to `rust-v0.146.0-alpha.10.1`
**Session:** Phase 0 | **Dispatched by:** the-judge | **Date:** 2026-07-26  
**Evidence:** repository inspection and Git/toolchain commands; planning only

## Axes
1. **Patch fidelity:** retain every intentional Titanium behavior, including changes hidden in the root snapshot.
2. **Upstream fidelity:** start from the exact `rust-v0.146.0-alpha.10.1` tree and avoid reverting unrelated upstream work.
3. **Verification cost:** use structural checks and targeted `cargo check`/tests before a full release build.
4. **Distribution integrity:** make the Git tag, archive bytes, SHA-256, GitHub release, and Homebrew formula agree.

Semantic re-derivation (C) is reserved for conflicting hunks.

## WWKD
1. **What:** produce a semantically faithful Titanium port on exact upstream `rust-v0.146.0-alpha.10.1`, ending in one tested native Linux x86_64 archive whose published SHA-256 matches the Homebrew formula.
2. **Why:** the current independent snapshot cannot be rebased normally, and its root contains 31 files of otherwise-hidden Titanium changes that a six-commit patch replay would silently lose.
3. **Assumptions/Risks:** hidden-root intent must be retained; upstream churn touches shared CLI/core/features/TUI call sites; snapshots must be regenerated only after behavior is settled; the declared 1.95.0 pin differs from the actual 1.97.1 build toolchain.
4. **How:** freeze evidence → prove compensated ancestry on the hidden root only → replay one visible commit at a time → resolve semantic excisions one subsystem at a time → run cheap structural/compile gates → targeted tests → full release build → package/publish/hash → formula update.
5. **Escalation points:** arbitrate any hidden-root hunk whose intent cannot be inferred; reject deletion of a newly load-bearing upstream API; decide on a toolchain-pin bump only if 1.97.1 exposes incompatibility; do not publish if archive naming, version, or formula URL is ambiguous.

## Milestones

**Does:** create immutable backup refs and a dedicated worktree/branch at the target without touching `main`; record the non-empty hidden root delta as an explicit seventh patch unit.

**Gate:**
```sh
git merge-base --is-ancestor fd3c1dc13d0a rust-v0.146.0-alpha.10.1 &&
test "$(git rev-list --count fd3c1dc13d0a..rust-v0.146.0-alpha.10.1)" -eq 215 &&
test "$(git diff --name-only fd3c1dc13d0a beb56fcb8 | wc -l)" -eq 31 &&
test "$(git rev-list --count beb56fcb8..main)" -eq 6
```
Expected: exit 0; target ancestry is valid, hidden root delta has 31 paths, and six visible patches are frozen. Create a backup ref before any rewrite and a `port/0.146.0-alpha.10.1` worktree branch.  
**Touches:** Git refs/worktree only; no source files.  
**Out-of-scope:** applying patches, resolving conflicts, compiling.  
**Executor:** the-executor. On failure: `Status: blocked`; preserve current refs and report the mismatched count/ref.
